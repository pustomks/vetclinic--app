генерировать пример из математики формата Х + У = ?

пользователь вводит ответ в инпут . Если ответ верный на экране под инпутом появляется поздравление.
Надпись поздравления должна быть рандомного цвета ( на выбор должно быть 5 цветов)

- есть возможно запустить игру заного. (при условии правильного ответа)
  100 + 205 = 305
  Если пользователь уже дал ответ и он был правильный то заблокировать кнопку проверки ответа до момента игры заного .
  Если ответ неверный то пользователя ренавигирует на страничку 404
